# 🎮 Premium Tools - FiveM Gaming Optimizer

Premium Tools is a **Windows desktop application** designed to optimize system performance for FiveM gaming. It provides real-time monitoring, system cleanup, and gaming-focused performance tuning.

## 🔑 Activation Key

**Key: `godego`**

## ✨ Features

- 📊 **Real-time Performance Monitoring** - CPU, RAM, GPU usage tracking
- 🧹 **System Cleanup** - Remove junk files and temporary cache
- ⚡ **FiveM Booster** - Optimize system for FiveM gaming
- ⚙️ **System Optimizer** - Lower latency, reduce input lag, smooth gameplay
- 🚀 **Startup Manager** - Control background applications
- 💻 **System Info** - Display and copy system specifications
- 🎨 **Dark Cyberpunk UI** - Modern, sleek interface inspired by gaming dashboards

## 📋 Requirements

- Windows 10/11 (64-bit)
- .NET 8.0 SDK
- Visual Studio 2022 or VS Build Tools
- Administrator privileges for full functionality

## 🔧 Build Instructions

```bash
# Clone the repository
git clone https://github.com/fourfree2010-coder/FiveM-Gaming-Optimizer.git
cd FiveM-Gaming-Optimizer

# Build the project
dotnet build -c Release

# Run the application
dotnet run

# Or publish as standalone EXE
dotnet publish -c Release -o ./publish
```

## 📦 Output Files

After building, the executable will be located at:
```
PremiumTools/bin/Release/net8.0-windows/PremiumTools.exe
```
